# LocalScribe

Lokalna transkrypcja plików dźwiękowych z wykorzystaniem modeli AI.

## Cel

Narzędzie ma przetwarzać nagrania przy użyciu modelu uruchomionego lokalnie, bez wysyłania plików audio do zewnętrznej usługi transkrypcji.

## Status

Repozytorium startowe — aplikacja nie jest jeszcze zaimplementowana.
Model, stos technologiczny, interfejs oraz formaty wejścia i wyjścia pozostają do ustalenia.
Nie ma jeszcze procedury instalacji, uruchomienia ani testów aplikacji.
